# STEP サンプルの置き場

ここに置いた STEP ファイル（`.stp`・`.step`）は、次の 2 つに使われます。

1. **アプリのサンプル** … 起動画面の「サンプルで試す」に並びます（サーバーがこのフォルダから配ります。置くだけで並びます）。
   STEP は部品の形状（B-rep）と組立の配置をすべて含むので、単独で組立全体を表示できます。
   アプリを人に渡すときはサンプルも含まれるので、社外に出せないファイルは置かないでください（作成者名などが記録されています）。
2. **解析の評価** … `npm test` が、全ての部品の形状が閉じたソリッドとして描けること、同じ部品の `.ipt`（[`samples/ipt/`](../ipt)）と
   寸法・穴が一致すること、同じ組立の `.iam`（[`samples/iam/`](../iam)）と配置が一致することを確かめます。

## 置き方

- GitHub の画面: このフォルダ（`program/samples/stp`）を開き、「Add file」→「Upload files」でファイルを追加
- 手元のリポジトリ: このフォルダにコピーしてコミット
