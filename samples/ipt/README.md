# ipt サンプルの置き場

ここに置いた Inventor の部品ファイル（`.ipt`）は、次の 2 つに使われます。

1. **ビューアのサンプル** … `npm run build` で配布フォルダのビューアに埋め込まれ、起動画面の「サンプルで試す」に並びます。
   配布するビューアに含まれるので、社外に出せないファイルは置かないでください。
2. **解析の評価** … `npm test` と `python -m unittest` が全ファイルを解析し、JS 版と Python 版の結果が一致するかを確かめます。
   新しいファイルを置いたら `python -m tests.golden` で正解データ（`tests/fixtures/ipt/`）を作ります。

## 置き方

- GitHub の画面: このフォルダ（`samples/ipt`）を開き、「Add file」→「Upload files」でファイルを追加
- 手元のリポジトリ: このフォルダにコピーしてコミット

見た目の確認用に、Inventor の画面のスクリーンショット（`.png`）も置けます（ビューアには埋め込みません）。

下の表の寸法・ねじはビューアの解析結果で、ファイル名・サムネイルと一致しています。これらは評価（`app/test/ipt-fidelity.test.mjs` の `SPEC`）の期待値にもなっています。
新しいファイルを置いたら、そこにも期待値を書き足してください（書かなくても、形状が閉じたソリッドとして描けるかは確かめられます）。
