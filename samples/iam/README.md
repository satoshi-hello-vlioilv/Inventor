# iam サンプルの置き場

ここに置いた Inventor の組立ファイル（`.iam`）は、次の 2 つに使われます。

1. **アプリのサンプル** … `npm run build`（起動ファイルも自動で実行）でアプリに埋め込まれ、起動画面の「サンプルで試す」に並びます。
   組立が参照する部品（`.ipt`）は、[`samples/ipt/`](../ipt) に同じ名前のファイルがあれば、それを使って組み立てて表示します。
   アプリを人に渡すときはサンプルも含まれるので、社外に出せないファイルは置かないでください
   （`.iam` には、保存した PC での部品のフルパス（ユーザー名を含む）が記録されています）。
2. **解析の評価** … `npm test` が、部品の参照・出現（配置）を読み、同じ組立を書き出した STEP（[`samples/stp/`](../stp)）と照合します。

## 置き方

- GitHub の画面: このフォルダ（`samples/iam`）を開き、「Add file」→「Upload files」でファイルを追加
- 手元のリポジトリ: このフォルダにコピーしてコミット

組立が使う部品の `.ipt` は `samples/ipt/` に置いてください。
同じ組立を Inventor で STEP に書き出したもの（`.stp`）を `samples/stp/` に同じ名前で置くと、配置の正しさを自動で確かめられます。
