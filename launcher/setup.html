Inventor 3Dツール

アプリを開く前に、準備が必要です

アプリの画面は、このリポジトリの app フォルダのソースから、起動のたびに自動で作ります。 作るための Node.js が見つからないか、作る途中で失敗したため、まだ開けません。

  1. Node.js（LTS 版）を入れる

    nodejs.org から Windows 版を入れるか、コマンドプロンプトで:

    winget install OpenJS.NodeJS.LTS

    入れた直後は、一度サインアウトすると設定（PATH）が反映されます。

  2. 起動ファイルをもう一度開く

    リポジトリの最上位の Inventor3Dツール.vbs をダブルクリックします。初回は必要なライブラリを入れてから作るので、 開くまでに少し（インターネット経由で数十秒）かかります。

  3. それでも開かないとき

    リポジトリのフォルダでコマンドプロンプトを開き、次を実行すると、失敗の理由が表示されます。

    npm install
npm run build

Inventor で部品を作る機能（変換データ .inventor.json を起動ファイルにドロップ）には、Python 3.10 以上も必要です。
